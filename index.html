About

~7 years in delivery

I'm a Senior DevOps Engineer with a software development background and about seven years of shipping software to production. Most of my work lives in Azure DevOps, where I design and run CI/CD pipelines, repositories and release processes, backed by Kubernetes, Terraform and AWS.

I'm also a .NET full-stack developer, building applications from the front end through APIs to the database, so I see delivery from both sides: the engineer pushing code and the operator keeping it running. Quality is part of the pipeline too: I write Selenium and Playwright test automation that runs on every release.

Recently I've moved into agentic AI to keep my skills in step with where the industry is heading. I'm building AI agents in Microsoft Copilot Studio that take routine work off business teams. I enjoy turning slow, manual processes into something that just runs.
